# Schul-OPSI Configuration Repository

OPSI package building, server automation scripts, unattend installers, and WinPE customizers.

## Directory Structure

- **OPSI-Produkte/**: OPSI product package sources (e.g. Journalpp, Xournalpp)
- **scripts-and-tools-OPSI/**: General OPSI server tools and diagnostic scripts
- **Win_unattanded/**: Unattended Windows installation XML files
- **WinPE/**: WinPE deployment scripts
- **winpe-builder/**: Highly-customizable WinPE image generator tools
- **tools/**: Extra admin utilities
- **archive/**: Abandoned/legacy OPSI package configurations
