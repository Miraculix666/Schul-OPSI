# Historical Script Archive (`toolkit/archive/`)

This directory contains legacy and historical iterations of WinPE generation scripts and hardening versions.

---

## 📜 Preserved Versions

- **`Hardening_V1.ps1` through `Hardening_V9.ps1`**: Evolution of Windows 11 hardening routines.
- **`WinPE_v10.3.ps1`, `WinPE_v13.5.ps1`, `WinPE_v14.0.ps1`**: Previous monolithic WinPE generation scripts.
- **`WinPE_maker_Per_v1.4.ps1`, `WinPE_maker_v6.3.ps1`**: Iterations of the customization layer.
- **`WinPE_ADK_Auto_Legacy.bat`**: Legacy batch launcher.
- **`Journalpp_legacy/`**: Legacy product packaging source.

> **Git History Notice**: All files in this archive retain their full commit history and authorship from Day 1 via Git rename tracking.
